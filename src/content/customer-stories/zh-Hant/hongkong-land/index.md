香港置地著手在數位轉型中現代化驗證體驗。挑戰在於：為**內部員工**與**外部合作仲介**兩類截然不同的對象，提供統一且安全的體驗，同時避免冗長上線週期與額外摩擦。透過 Authgear，他們在數週內（而非數月）推出雙重受眾驗證：員工使用 ADFS 登入、仲介使用電子郵件／密碼加 2FA、雙方皆可於行動裝置使用生物辨識，並搭配管理後台自動化。

## 重點摘要

- **產業：** 物業投資、管理及發展
- **使用者：** 內部員工與外部合作仲介
- **使用情境：** 統一的企業與合作夥伴驗證
- **驗證方式：** 員工 ADFS；仲介電子郵件／密碼＋2FA；行動裝置生物辨識（Face／Touch）
- **成果：** 更快上線、降低 IT 負擔、在減少摩擦下強化安全

## 挑戰

- **兩類受眾、一套系統：** 在需求各異下服務內部員工與外部仲介
- **安全與速度：** 在傳統需 **3–6 個月** 的上線時程與嚴格合規間取得平衡
- **量身登入流程：** 為各群組提供不同但協調一致的驗證路徑
- **行動友善存取：** 在嚴格密碼規則下降低摩擦
- **IT 效率：** 降低使用者與政策管理的營運負擔

## 解決方案：為安全與易用打造的雙軌系統

Authgear 支援**雙軌**做法，在統一安全控管的同時，依受眾調整體驗：

1. **內外部使用者整合驗證**　員工透過 **ADFS** 與企業憑證登入；外部仲介使用**電子郵件／密碼搭配雙因素驗證（2FA）**——皆在同一平台內完成。
1. **複雜密碼政策**　在全組織強制重設週期、密碼歷史與強度規則，並保留必要彈性。
1. **行動裝置生物辨識**　Face／Touch ID 為員工與仲介減少摩擦，與嚴格密碼政策相輔相成。
1. **透過 Admin API 簡化管理**　對使用者、角色與驗證設定的細緻控制，**減少手動管理工作**並簡化營運。

## 成果：企業級安全，數週內交付

- **企業級安全，數週內上線**——而非數月
- **零信任思維與角色型存取** 涵蓋各使用者群組
- **更快、更輕鬆的行動登入** 在嚴格密碼規則下仍可使用生物辨識
- **ADFS 與 2FA** 無縫處理複雜的混合受眾情境
- **降低 IT 負擔** 透過 Admin API 自動化與集中政策
- **可擴充架構** 為未來整合做好準備

## 為何選擇 Authgear

- **速度＋彈性：** 為員工與合作夥伴量身打造流程，無需冗長上線
- **企業安全：** 2FA、進階密碼政策與集中強制
- **行動優先體驗：** 內嵌、符合品牌的體驗與 Face／Touch ID
- **營運掌控：** Admin API 支援自動化佈建與政策管理

## 功能亮點

- **ADFS 整合** 企業登入
- **電子郵件／密碼＋2FA** 外部仲介
- **生物辨識登入（Face／Touch）** 行動低摩擦存取
- **複雜密碼政策**（重設、歷史、強度）
- **Admin API** 使用者／角色生命週期與政策控管
