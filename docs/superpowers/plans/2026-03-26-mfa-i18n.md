# MultiFactorAuthenticationPage i18n Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Convert `MultiFactorAuthenticationPage.tsx` from hardcoded English strings to next-intl translations supporting English (`en`) and Traditional Chinese (`zh-TW`).

**Architecture:** Add a `MultiFactorAuthentication` namespace to both JSON message files, then update the component to call `useTranslations('MultiFactorAuthentication')` and `useTranslations('Features')` (for shared CTA strings). Locale is resolved automatically from the `x-locale` request header — no prop changes needed.

**Tech Stack:** next-intl, TypeScript, React Server Components
